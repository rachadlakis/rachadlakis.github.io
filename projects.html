OMNI-Train

Distributed PyTorch fine-tuning framework — built a CLI and web application for training PyTorch and Hugging Face models with DDP and FSDP, mixed precision, gradient checkpointing, layer prefetching, PEFT, and quantization. Validated distributed training across eight GPUs on RunPod.

GitHub
2025

Histor

Video search, evidence retrieval, and alerts — built a video intelligence pipeline that indexes camera frames as searchable embeddings using YOLOX, CLIP, and ViTPose. Enabled an LLM agent to answer natural-language questions over stored video and cite evidence frames; added live alerts for zones, poses, fire, and smoke. Trained a YOLOv9 fire-and-smoke detector on 22,800 images; evaluated at mAP50 0.69 and approximately 100 ms per frame on CPU. Diagnosed a threefold throughput regression and an early-stopping/resume issue from run logs.
